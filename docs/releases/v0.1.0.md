# draft-revise v0.1.0 — Codex skill

English | 中文

First public release of **draft-revise**, a community skill for **OpenAI Codex**.

- Revise documents from PDF comments while preserving evidence and original files.
- Review precise original/revised fragments and sentences in a standalone offline HTML.
- Navigate hierarchical contents, exact text/page locations, formulas and a responsive comment sidebar.
- Default completed explicit edits to accepted; collect opinions only on pending requirements.
- Export feedback schema 2 and preserve pending instructions for the next revision.

**Compatibility:** feedback schema 2 only; ledger schema 1. Release version numbers are independent of these schemas. Source editing and document compilation require suitable tools in the Codex environment.

Download `draft-revise-v0.1.0.zip` or `.tar.gz`, extract it, then copy the enclosed `draft-revise/` folder into your Codex skills directory. The archive also includes installation documentation and the MIT license. Verify downloads against `SHA256SUMS`.
