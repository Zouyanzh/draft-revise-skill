## 0.1.0 — 2026-11-17

First public release of **draft-revise, a skill for OpenAI Codex**.

- Preserve PDF annotation evidence and connect comments, requirements and edits.
- Generate an offline HTML review with hierarchical contents, complete document text, exact highlights and a responsive comment sidebar.
- Compare original/revised fragments, complete sentences and expandable paragraphs; preserve native MathML and page evidence.
- Accept completed explicit edits by default and collect opinions only for unresolved requirements.
- Export/import feedback schema 2 and carry pending opinions into the next revision plan. Earlier feedback formats are rejected.
- Include synthetic report/slides regressions, continuous integration, bilingual documentation and reproducible release packages.

**首个公开版本：面向 OpenAI Codex 的 draft-revise skill。**

- 保留 PDF 批注证据，关联批注、要求与修改。
- 离线 HTML 提供分层目录、完整正文、精确高亮和响应式批注侧栏。
- 对照原始／修订片段、完整语句与可展开段落，保留 MathML 公式及页面证据。
- 明确修改默认接受，仅待决项填写意见。
- 仅支持反馈 schema 2，完整保留下一轮所需的待决意见，拒绝旧反馈格式。
- 提供合成报告／幻灯片回归测试、持续集成、中英文文档和可复现发布包。
